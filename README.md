# Lrcli

A simple CLI interface for [LrcLib](https://lrclib.net) built with rust

## Usage:

```bash
lrcli search -t <track_name> -a <artist> [-b album] [-d duration]
Options:
  -t, --track       Set the track name
  -a, --artist      Set the artist name
  -b, --album       Set the album name
  -d, --duration    Set the duration (in seconds)
```
